# Instructions for Claude

This repository is **IoT for Young Makers**, a beginner IoT course for ages 10–15.
Before changing anything, read `AGENT.md` (how lessons are built and taught) and `ROADMAP.md` (what's next).

- Follow the teaching rules in `AGENT.md`: one new idea per lesson, and a "why" for every wire, hole and line of code.
- Test lesson changes with `tools/check.sh lessons/<slug> "<steps>"` and look at the screenshots.
- When asked (for example with `@claude` on a pull request), make the requested fix on that pull request's branch.
  Never push to `main` and never merge.
