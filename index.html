What you need

You can do every lesson on screen first. To build it for real, you need:

  • ESP32 DevKit V1 board (30 pins) and a USB data cable that fits it (micro-USB or USB-C)
  • A breadboard and a few male-to-male and female-to-male jumper wires
  • 3 LEDs (red, yellow, green) and 3 × 330 Ω resistors
  • Later: a push button, a small buzzer, a light sensor (LDR) and a 10 kΩ resistor
  • A computer with Thonny (free) to send MicroPython code to the ESP32

For parents and teachers

Lessons run in the browser and save progress only on this device. No accounts, and no personal data is collected.

The animations show how circuits work. They are not safety tests, so please check real circuits before they are plugged in.

New lessons are added regularly. Lessons marked “coming soon” are on the way.
